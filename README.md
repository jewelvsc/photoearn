## 🚀 সেটআপ ও লাইভ করার নিয়ম (Step-by-step Setup Guide)

### ধাপ ১: সাবডোমেন তৈরি করা (`photoearn.chasherdokan.com`)
1. আপনার হোস্টিংয়ের **cPanel**-এ লগইন করুন।
2. **Subdomains** অপশনে যান।
3. সাবডোমেনের ঘরে লিখুন: `photoearn` এবং ডোমেন সিলেক্ট করুন `chasherdokan.com`।
4. ফোল্ডার রুট হিসেবে সাধারণত `public_html/photoearn` তৈরি হবে। **Create** বাটনে ক্লিক করুন।

### ধাপ ২: ফাইলগুলো আপলোড করা
1. এই ফোল্ডারের সব ফাইল (`index.html`, `admin.html`, `css`, `js`) জিপ (zip) করুন।
2. cPanel-এর File Manager থেকে `public_html/photoearn` ডিরেক্টরিতে জিপ ফাইলটি আপলোড করে **Extract** করে দিন।
3. এখন ব্রাউজারে `https://photoearn.chasherdokan.com` লিখলেই সাইট লাইভ দেখতে পাবেন!
